# millworkdev/solver-mcp

Public **publishing repository** for the npm package
[`@millwork/solver-mcp`](https://www.npmjs.com/package/@millwork/solver-mcp) —
the Millwork Solver execution MCP server.

- This repository holds a **curated export**: exactly the contents of the
  published package tarball, plus the pinned publish workflow. It is not a
  mirror of any working tree.
- The **canonical source is private**. Development, tests, and history live
  elsewhere; nothing here is the place to change the package.
- **No issues or support here.** This repository does not accept issues,
  discussions, or support requests. Use the support channel referenced in the
  published package documentation.

Publishing happens only through the pinned GitHub Actions workflow in this
repository via npm trusted publishing (OIDC), under explicit operator
approval.
