# Support

Start with the [Millwork documentation](https://docs.getmillwork.dev).

For non-sensitive package, configuration, or compatibility problems, open an
[issue](https://github.com/millworkdev/solver-mcp/issues). Include the package
and Node versions, the tool name, a minimal reproduction, and safe error fields.
Remove credentials, customer content, and tenant or resource identifiers.

Suspected vulnerabilities do not belong in public issues. Follow
[SECURITY.md](SECURITY.md) and use the private route only when GitHub shows it
as available.

Before 1.0, support covers the current promoted minor and the immediately
previous minor for 90 days after a new minor is promoted. Repository files or
pre-promotion builds do not create an availability or support promise.
